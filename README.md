# ChurnSense AI 🚀

AI-powered customer churn prediction system using ML models.

## 📌 Problem
Companies lose customers without knowing why. ChurnSense predicts churn risk before it's too late.

## 🧠 Tech Stack
- Python
- Scikit-Learn
- Pandas
- Streamlit
- XGBoost

## 📊 Features
- Customer churn probability prediction
- Feature importance visualization
- Interactive dashboard
- Model evaluation metrics
